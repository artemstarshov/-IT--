# Анализ работы мобильного учебного приложения

## Цель
Проанализировать последовательность операций в модуле мобильного учебного приложения и представить схему типового сценария: от запуска приложения до завершения урока и синхронизации прогресса.

## Объект анализа
Модуль мобильного приложения:  
«Запуск приложения → Просмотр списка курсов → Выбор курса → Просмотр уроков → Отметка урока как пройденного → Отслеживание прогресса → Завершение сессии → Синхронизация данных с сервером».

## Участники (актеры)
- Пользователь (студент)  
- Система (мобильное приложение)  
- Сервер (сохранение прогресса и синхронизация данных)

## Предусловия
- Пользователь авторизован в системе.  
- Курсы опубликованы и содержат хотя бы один урок.
